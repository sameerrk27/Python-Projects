# Simple Calculator

A simple Python mini-project that performs basic arithmetic operations.

## Concepts
- Variables
- Operators
- User input

## Description
This project asks the user to enter two numbers and an operator, then performs the selected operation.

## How to Run
```bash
python main.py
```

## Example
```bash
Enter first number: 10
Enter second number: 5
Choose an operation (+, -, *, /): +
Result: 15
```
