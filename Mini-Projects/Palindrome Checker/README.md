# Palindrome Checker

A simple Python mini-project that checks whether a word reads the same forward and backward.

## Concepts
- Strings
- Slicing
- if-else

## Description
This program asks the user to enter a word and checks whether it is a palindrome.

## How to Run
```bash
python main.py
```

## Example
```bash
Enter a word: level
It is a Palindrome!
```
