# Word Counter

A tiny Python project that counts the number of words and characters in a sentence entered by the user.

## Project Overview
This project takes a string input, splits it into words, and then prints the total word count and character count.

## Files
- `WordCounter.ipynb` - Jupyter notebook containing the code
- `word-counter.png` - example screenshot

## How to Run
1. Open the `WordCounter.ipynb` file in Jupyter Notebook or VS Code.
2. Run all cells.
3. Enter a sentence when prompted.

## Example Output
```text
Enter a sentence: Hello World!
Total words: 2
Total characters: 12
```

## Requirements
- Python 3
- Jupyter Notebook
