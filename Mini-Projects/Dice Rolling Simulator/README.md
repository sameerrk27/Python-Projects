# Dice Rolling Simulator

A fun mini Python project that simulates rolling a dice until the user decides to stop.

## Project Overview
This project uses Python's `random` module to generate a number between 1 and 6 each time the user chooses to roll the dice.

## Files
- `main.py` - main project logic
- `DiceRollSimulator-screenshot.png` - example screenshot

## How to Run
```bash
python main.py
```

## How It Works
- The program asks: `Roll the dice? (yes/no)`
- If the user enters `yes`, it generates a random number from 1 to 6.
- If the user enters `no`, the program exits gracefully.

## Example Output
```text
Roll the dice? (yes/no): yes
You rolled: 4
Roll the dice? (yes/no): no
Thanks for playing!
```

## Requirements
- Python 3
