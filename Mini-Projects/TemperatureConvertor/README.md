# Temperature Converter

A simple Python mini-project that converts Celsius into Fahrenheit.

## Concepts
- Mathematical formulas
- Operators

## Description
This program takes temperature in Celsius and converts it into Fahrenheit using the formula:
F = (C × 9/5) + 32

## How to Run
```bash
python main.py
```

## Example
```bash
Enter Temperature in Celsius: 30
Temperature in Fahrenheit: 86.0
```
