# Text Editor App

A simple Python mini-project that creates a basic desktop text editor using Tkinter.

## Concepts
- GUI programming
- Tkinter widgets
- File handling
- User input and text editing

## Description
This application allows the user to create a new file, open an existing text file, save the file, and exit the editor.

## How to Run
```bash
python main.py
```

## Features
- New file
- Open file
- Save file
- Save as
- Exit program

## Example
```bash
Open the app and type your text in the editor.
Choose File > Save to store your work.
```
