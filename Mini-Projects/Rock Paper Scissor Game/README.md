# Rock Paper Scissor Game

## Problem Statement

This Python game lets a user play Rock, Paper, Scissors against the computer. The user chooses rock, paper, or scissor, and the computer randomly selects one of the three options. The program compares both choices and displays the result.

## Workflow

1. The user enters **rock**, **paper**, or **scissor**.
2. The computer randomly chooses rock, paper, or scissor.
3. The program displays both choices and announces whether the user wins, the computer wins, or it is a tie.

## Game Rules

- Rock vs. Rock: Tie
- Rock vs. Paper: Paper wins
- Rock vs. Scissor: Rock wins
- Paper vs. Paper: Tie
- Paper vs. Rock: Paper wins
- Paper vs. Scissor: Scissor wins
- Scissor vs. Scissor: Tie
- Scissor vs. Rock: Rock wins
- Scissor vs. Paper: Scissor wins

## Output

The game displays the user's choice, the computer's choice, and the result of the round.
