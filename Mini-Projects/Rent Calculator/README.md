# Rent Calculator

## Problem Statement

I live in a flat with my 3 roommates, and at the end of the month there is often confusion about how much each person should pay for shared expenses such as rent, food, and electricity.

We need to calculate the total of all expenses and divide it equally among 4 people, so that everyone knows how much they should contribute.

## Inputs

The program asks the user to enter:

- Total rent
- Total food cost
- Electricity units used
- Cost per electricity unit
- Number of people living in the flat

## Process

The program should:

1. Calculate the electricity bill using:
   - Electricity cost = electricity units × cost per unit
2. Add all expenses together:
   - Total amount = rent + food cost + electricity cost
3. Divide the total by the number of people living in the flat.

## Output

The program should display:

- The total amount to be paid
- The amount each person should pay
